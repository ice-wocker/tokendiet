三项底层设计原则

告别臃肿的 npm 构建链与死板的文本拼接，专注于纯粹的工程表达。

01 · AST 语义级骨架化

Python 使用标准库 AST，其他语言采用结构感知的括号解析。保留常见声明与函数签名、折叠实现；解析器不是完整编译器，输出适合上下文摘要而非代码重构。

02 · 更安全的上下文默认值

常见凭据会经启发式规则脱敏，.env 默认不进入上下文；独立审计也会扫描环境文件。检测不是完备 DLP，发送前仍应检查输出。

03 · 仓库感知与可控压缩

尊重分层 .gitignore 与自定义排除规则。可聚焦指定路径，也可设置预算尝试逐级折叠；所有 Token 与预算均为启发式估计。
